# TIA Portal V19 Integration

## Scope

Only Siemens TIA Portal V19 and its corresponding Openness integration are supported.

## Isolation

`EngineerPc.Tia.V19` is the only project permitted to reference Siemens.Engineering.

## Integration workflow

1. Detect/configure TIA V19.
2. Establish TIA session.
3. Open project.
4. Read project context.
5. Perform typed operations.
6. Compile.
7. Collect diagnostics.
8. Close project/session safely.

## API verification rule

All Siemens API calls must be verified against the locally installed V19 assemblies. Do not rely on generated guesses.
